# Studio 0.23 — визуальный выбор и понятные настройки

Вместо списка названий типов подсветки — галерея 22 анимированных эффектов.
Миниатюры показывают клавиатуру с корпусом, широкими клавишами, пробелом,
отдельным функциональным рядом и энкодером. Та же геометрия используется
в ленте режимов, большом редакторе и предпросмотре заряда.
Галерея использует текущую палитру, скорость и преобразование цвета AJKS.
Спокойные, динамичные и реактивные эффекты можно смотреть отдельно.
Для отклика миниатюра моделирует нажатие; системный ввод не перехватывается.

Нажатие миниатюры меняет только тип эффекта. Палитра, область клавиш,
слои и параметры сохраняются. Наведение, Escape, «Готово» и закрытие фона
не применяют просматриваемый эффект. Если редактируется режим клавиатуры,
действует прежнее автосохранение после паузы. Локальная сцена остаётся
черновиком до явного добавления на клавиатуру.

В ленте выделение обозначено рамкой; отдельная точка показывает активный
режим устройства. Видна одна карточка добавления, остальные пустые слоты
не занимают место. Редактор остаётся доступен во время автоматической записи.
Слои, ручные параметры и экспорт раскрываются по запросу.

В настройках клавиатуры основные разделы — отклик, назначения и энкодер.
Настройки отклика расположены рядом со схемой выбранных клавиш. Поля
Rapid Trigger появляются при его включении. Действия энкодера и заряд
разделены на две панели; отключённый индикатор скрывает свои параметры.
Мышь получила две панели отклика и чувствительности. Импорт, экспорт
и восстановление находятся в меню страницы; запись параметров мыши
сохраняет проверку, резервную копию и явную кнопку сохранения.

В доке сохранена выбранная пользователем лента, крупный предпросмотр
и инспектор рядом. Данные ПК поступают автоматически при наличии
включённых страниц сводки, CPU или RAM, включая работу в трее.
Кнопки запуска потока не нужны. Страница календаря остаётся автономной.
Источник FPS выбирается среди активных игр; переключение в Studio
не сбрасывает живой источник. Для ETW Windows может запросить повышенные
права через отдельное действие «Включить FPS…». Реальная проверка FPS
в Overwatch и других играх этой сборки ещё не выполнена.

OLED 0704b908fd5f уже установлен на доке пользователя: подтверждён
design_version=1, настройки, список страниц и число медиаресурсов сохранены.
Повторная прошивка для интерфейса 0.23 не требуется. Физическая оценка
читаемости нового оформления ещё не получена.

Проверка: 131 тест Rust, clippy с запретом предупреждений и release-сборка.
17 состояний реального egui-интерфейса экспортируются без окон, устройств
и чтения пользовательской сессии. Проверяются зазоры карточек и доступность
основных элементов при 1280×880 и 1100×740, включая Rapid Trigger,
отключённый индикатор, сохранение и запрос разрешения FPS.
Отдельные проверки вводом мыши и Escape подтверждают поведение галереи;
геометрия проверяет все 82 клавиши и отсутствие пересечений с энкодером.

Принципы компоновки и постепенного раскрытия:
[Apple HIG: Layout](https://developer.apple.com/design/human-interface-guidelines/layout),
[Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls).

Воспроизведение:

```powershell
.\scripts\dev.ps1 test
.\scripts\dev.ps1 clippy
.\scripts\dev.ps1 release
Start-Process -FilePath .\target\release\ajazz-studio.exe -ArgumentList '--render-review','artifacts/ui-review-023' -WindowStyle Hidden -Wait
python tools/render_ui_review.py artifacts/ui-review-023
```

Для последней команды нужны NumPy и Pillow. Самой Studio Python не нужен.
Изображения предпросмотра используют демонстрационные значения датчиков.
