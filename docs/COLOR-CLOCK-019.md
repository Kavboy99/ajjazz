# Цвет и скорость подсветки — Studio 0.19.0

Исправление состоит из приложения и экранно-независимого расширения AJKS
клавиатуры AK820MAX ULTRA. 24.10.2026 образ 94bca305ce09 установлен с согласия пользователя.
Клавиатура отвечает build 9ad77b0e5c6e44af. Пользователь подтвердил:
«Да, теперь соответствует» — оттенки, яркость и темп.

## Причины расхождения

Предыдущая прошивка увеличивала время анимации при каждом вызове обработчика
основного цикла. Предпросмотр использовал 50 шагов в секунду. Частота основного
цикла не является таймером, поэтому одинаковый параметр скорости давал разный
результат. Кроме того, предпросмотр игнорировал общую яркость, скорость и паузу,
изменённые энкодером, и начинал анимацию заново по длительности локальной сцены.

Цвет редактора хранится в sRGB, а штатный LED-драйвер принимает линейную
мощность. Прямая передача кодов меняла относительную яркость смешанных каналов.
Перестановки RGB-каналов нет; исходный сериализатор передаёт GRB.

## Исправление

- Время MCU берётся из штатного миллисекундного HAL-счётчика 20000238.
  Один логический шаг равен 20 мс. Учтены остаток времени, пауза и переполнение.
  Повторные вызовы обработчика в ту же миллисекунду не ускоряют анимацию.
- Цвет переводится из sRGB в линейную мощность, затем округляется к штатному
  шестибитному PWM. Максимальный белый остаётся 63, как у исходного драйвера.
  Предпросмотр показывает обратное преобразование этой же квантованной мощности.
  Формула: [W3C CSS Color 4](https://www.w3.org/TR/css-color-4/#color-conversion-code).
- Ответ AJKS расширен меткой CLK2: текущий кадр, миллисекунды, выбранный режим,
  яркость, скорость, пауза и версия цветового преобразования. Старый ответ
  корректно распознаётся без объявления синхронизации.
- Studio читает короткий статус раз в секунду в соответствующем разделе.
  Между чтениями предпросмотр продолжает отсчёт самостоятельно. Чтение не
  передаёт RGB-кадры и не пишет flash; при ошибке автоматические попытки
  прекращаются до «Обновить». Анимация остаётся автономной при закрытом приложении.
- Общие яркость/скорость и пауза учитываются в предпросмотре. Длительность
  локальной сцены больше не сбрасывает время автономного режима.

## Проверка

117 тестов Rust, clippy с запретом предупреждений, форматирование и release.
26 сценариев ARM-эмуляции. Проверены 1000 мс = 50 шагов при нерегулярных вызовах,
исходный SysTick/обработчик HAL, пауза, переполнение и несколько смешанных цветов
через оригинальные PWM и GRB-сериализатор. 52 кадра всех алгоритмов сверены
между Rust и скомпилированным ARM-кодом. Сжатая инициализация RAM разобрана и
побайтно сверена с исполнением исходного scatter-loader: 4288 байт.
