# Свой экран — Studio 0.26 / OLED UI3

Вместо отдельных страниц с похожими показателями можно собрать один экран из
одного, двух, трёх или четырёх разных значений. Доступны FPS, CPU, RAM, GPU,
VRAM, температуры CPU/GPU/диска/платы, мощность GPU и время. Состав меняется
прямо в инспекторе; порядок — через меню строки. Повтор одного показателя
внутри композиции исключён. Готовые композиции дают удобную отправную точку.

Расположение подстраивается автоматически: один крупный блок, две строки,
главный блок с двумя дополнительными или четыре ячейки. Цифры уменьшаются,
если длинное значение не помещается. Метки и единицы остаются отдельными.
Ручных координат, наложений и выбора размера шрифта для этого режима нет.
Полосы загрузки можно включить отдельно для своей композиции.

Оформление выбирается в отдельной галерее с анимированными миниатюрами:
Тишина, Дыхание, Орбита, Волна, Светлячки, Сканер. По умолчанию анимация выключена.
Декор занимает края дисплея и не перекрывает цифры. Цвета, общий стиль и яркость
сохраняют прежние настройки. Это алгоритмы в OLED-прошивке: Studio передаёт
показания и компактное описание композиции, а не изображения с ПК.

Часы, календарь, фокус, секундомер, фото/GIF остаются самостоятельными функциями.
Прежние макеты доступны отдельно; существующий список не переписывается при
открытии новой версии. Удаление страницы из списка не стирает файл изображения.

## Поведение

Настройки сохраняются автоматически после редактирования, как у прежних страниц.
Кнопка дока выбирает сохранённые страницы без запущенного приложения. Время и
декор автономны; новые показания компьютера требуют Studio, в том числе в трее.
Недоступные данные становятся прочерками. Композиция только с часами не запускает
сбор показателей. Длительность своей страницы при автопереключении: 1–255 секунд.

OLED UI2 продолжает показывать прежние страницы. Новый конструктор требует UI3;
проверка версии блокирует отправку неподдерживаемой композиции до первого SET.
Установка нового образа выполняется отдельно через «Обновления».

## Проверки

Размер записи страницы не изменён: восемь страниц помещаются в прежние 48 байт
с CRC. Резерв RAM остаётся 512 байт, прежняя область настроек не расширяется.
Метрики упакованы четырьмя полубайтами; тип записи кодирует фон и наличие полос.
Существующие форматы страниц и медиаресурсы не меняются.

Проверяются Rust/C кодеки, геометрия, все шесть оформлений, живые/отсутствующие
данные и границы значений, совпадение каждого пикселя, сохранение/загрузка,
автоматическая длительность и задняя кнопка без хоста. Сохраняются прежние
регрессии Stop/native, таймеров, изображений/GIF и телеметрии.

Проектирование опирается на приоритет главной информации и постепенное раскрытие
настроек из [Apple HIG — Layout](https://developer.apple.com/design/human-interface-guidelines/layout)
и [Widgets](https://developer.apple.com/design/human-interface-guidelines/widgets).
Крупные цифры и максимум четыре ячейки выбраны с учётом физических 128×128 точек.
