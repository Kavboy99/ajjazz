# Обновления из Studio

Раздел **Настройки → Обновления** содержит пакеты для трёх точных моделей:

| Устройство | Включённый пакет |
|---|---|
| APEX Dock ID1759 / OLED104 | AJSC OLED UI4, b634c6a1d417, только экранный компонент |
| AK820MAX ULTRA 0C45:80A0 / AJKS fd469e3144ab533c | Переустановка AJKS 8b3d2d61ebfd с переносом текущих режимов |
| AJ159 APEX ID1755 | Штатная прошивка мыши 3.02 от поддержки |

Имя APEX недостаточно для совместимости: ID2349/2350 не поддерживаются.
Установщик датчиков CPU PawnIO также включён в пакет, в карточке «FPS и датчики».
Отдельные приложения мониторинга и скачивание обновляторов не требуются.
Сохраняйте рядом с EXE каталог tools из дистрибутива.

## Последовательность

1. **Обновить…** временно останавливает обмен с устройствами, проверяет файлы
   по встроенному SHA256 и читает точную модель. Клавиатура и мышь прошиваются
   только в проводном режиме; приложение само проверяет наличие нужного подключения.
2. Studio сохраняет доступные настройки в `%LOCALAPPDATA%/AjazzStudio/backups`.
   У клавиатуры восемь актуальных программ, пустые слоты, яркость/скорость,
   действия энкодера и индикатор заряда переносятся в подготовленный образ.
   Его контрольная сумма в штатном контейнере пересчитывается. Код обновлятора,
   загрузчик и остальные участки образа не изменяются этой операцией.
3. После успешной подготовки появляется подтверждение с моделью и резервной копией.
   **Отмена**, Escape и закрытие фона не запускают обновлятор. Черновики остаются.
4. **Открыть обновление** запускает проверенный OEM-движок AJAZZ из пакета Studio.
   Сейчас он использует своё штатное окно: для дока нажмите OLED, для клавиатуры — Start.
   Сетевой сервис производителя для этого не нужен. Studio не рисует выдуманный
   процент: фактический ход записи показывает окно AJAZZ.
5. После закрытия движка Studio повторно читает устройство. Код завершения 0 сам
   по себе не считается доказательством успешной записи. Для дока проверяется UI4;
   для клавиатуры — ответ и точное соответствие режимов/конфигурации копии.
   После клавиатуры доступен переход в калибровку.

При ошибке проверки пакет не запускается. Если клавиатура изменилась между
подготовкой и подтверждением, требуется новая подготовка, чтобы не потерять
свежие режимы. Прошивка мыши ограничена штатной 3.02: собственной модифицированной
прошивки мыши в этом выпуске нет.

## Что сохраняется и что не обещается

OLED-пакет не содержит USB/RF-образов и не стирает пользовательские фото/GIF.
Их пиксели не входят в резервную копию: читаются только настройки/список и метаданные.
Копия мыши по радиоканалу может быть недоступна; это явно показывается до подтверждения.
Снятие заводской калибровки и аппаратное восстановление программатором не проверены.
После клавиатурной прошивки нужна калибровка каждой физической клавиши.

Проверки кода: список точных пакетов/безопасных путей, отказ при изменении файла,
перенос программы и семи пустых слотов без изменения остальных байтов контейнера,
контрольная сумма OEM и отмена диалога без запуска. Headless-предпросмотр не запускает
движки и не обращается к HID. Новые кнопки ещё требуют проверки на физических
устройствах; наличие кнопки не означает, что все три устройства были повторно прошиты.
