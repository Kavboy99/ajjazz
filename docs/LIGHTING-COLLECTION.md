# Studio 0.24 — коллекция подсветки

Из 30 образцов отобраны 18 новых композиций. Ориентиром стали понравившиеся
пользователю «Светлячки»: тёмное пространство, локальные огоньки и живое движение.
Для разнообразия оставлены кометные потоки, дождь, мягкие цветовые полотна
и два режима с реакцией на нажатия. В каждом образце сочетаются 3–4 слоя,
их области клавиш, скорости, фазы, направления и смешивание.
В подборке нет композиций, различающихся только палитрой.

В разделе **Подсветка → Коллекция** все режимы видны в анимации. Нажатие добавляет
режим в свободный слот и включает его через обычное проверяемое автосохранение.
Карточка «+» также открывает коллекцию. «С нуля» создаёт режим с одним слоем.
Наведение, прокрутка, Escape и закрытие коллекции не меняют память клавиатуры.

В клавиатуре восемь мест. В библиотеке Studio доступны все 18 композиций;
если память заполнена или клавиатура не подключена, выбранный образец
открывается как локальный черновик. Занятые места и другие черновики сохраняются.
Для записи такого черновика нужно освободить место и нажать «Добавить на клавиатуру».
После подтверждённого удаления старые отложенные правки этого слота больше
не возвращают удалённый режим. Ошибка удаления оставляет проект без изменений.

Первыми показаны «Живой лес», «Люмина», «Созвездия», «Медные угли», «Пыльца»
и «Ночной сад». Затем — «Метеоры», «Лунная рябь», «Звёздный ветер», «Ночной город»,
«Орбитальный след», «Неоновый дождь», «Сонар», «Эхо», «Шёлк», «Северный свет»,
«Вишнёвый дым» и «Магнитное поле».

[Оценки всех 30 образцов и причины отбора](LIGHTING-SELECTION.md).
Баллы отражают предпочтение пользователя и редакторскую оценку композиции,
выразительности движения и отличий от других выбранных режимов.

Композиции выполняет установленная AJKS-прошивка 8b3d2d61ebfd. Используются
существующие команды и эффекты; новая прошивка и поток кадров с ПК не нужны.
Проверка Unicorn исполняет именно этот неизменённый ARM-образ: 18 композиций,
72 контрольных кадра, 82 физических LED и преобразование цвета совпали с Rust.
Проверка физической яркости и аппаратного времени новых композиций отдельно
не проводилась. Предпросмотр учитывает шестибитный PWM и ранее проверенное
преобразование цвета; GIF-примеры показывают 12 секунд движения при 15 кадрах/с.

Также исправлено восстановление направления из целочисленных компонентов:
чтение и повторная сборка не меняют нетронутое направление. Проверены 36 000
исходных углов, все выбранные программы проходят точный цикл encode/decode.

Для самостоятельного импорта отдельные проекты находятся в `examples/collection/`.
Они содержат только параметры сцены. При обычном использовании импорт не нужен:
коллекция уже встроена в приложение.

Проверка разработчика:

```powershell
python tools/design_lighting_collection.py
.\scripts\dev.ps1 test
.\scripts\dev.ps1 clippy
.\scripts\dev.ps1 release
.\target\release\ajazz-lab.exe lighting-collection-audit research/lighting-collection/candidates.json artifacts/lighting-studies
python tools/render_lighting_studies.py artifacts/lighting-studies
python tools/emulate_lighting_collection.py
```

Для инструментов нужны Pillow/NumPy, для ARM — Unicorn из исследовательского
окружения. Обычному приложению эти компоненты не требуются.
