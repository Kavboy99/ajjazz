# AJAZZ Studio 0.18 — основные сценарии

- Настройки загружаются при первом открытии раздела. Ошибка не запускает цикл
  повторных обращений; «Обновить» повторяет чтение вручную.
- «Подсветка → Мои режимы»: карточка открывает режим. Черновики разных слотов
  хранятся раздельно в локальном сеансе. Прежняя локальная сцена доступна из «•••».
- «Сохранить и включить» записывает изменённую программу, выбирает её и сохраняет
  выбор для следующего питания. Неизменённая программа повторно не загружается.
  Другие слоты проверяются побайтно; перед изменением сохраняется копия.
- «Клавиатура → Энкодер»: изменения объединяются после паузы650мс и сохраняются
  автоматически. Записываются только назначения, с актуальными яркостью, скоростью,
  паузой и режимом, прочитанными непосредственно перед записью. При ошибке нет
  автоматического повтора записи. Можно повторить сохранение отдельной кнопкой.
- Калибровка начинается только кнопкой пользователя, сохранение доступно после82/82.
- Экран дока: основная кнопка «Сохранить на доке» применяет и сохраняет. Временное
  применение и загрузка оформления с устройства находятся в «•••».
- Диагностика и сведения об устройствах находятся в «Дополнительно».
- Локальный предпросмотр не отправляет кадры клавиатуре. Пауза в редакторе меняет
  только предпросмотр; устройство продолжает выбранную программу.

Проверено:115 тестов, clippy, fmt, release и упаковка. В реальном GUI проверены
Publish/Activate/автосохранение энкодера с readback и возвратом исходных программ
и назначений. Проверены автоматическое чтение клавиатуры/мыши/дока, сохранение
локальных черновиков и перезапуск приложения. Новая прошивка не устанавливалась.
